# OpenObserve Provider

The **OpenObserve** provider lets you manage [OpenObserve](https://openobserve.ai) resources — streams, dashboards, users, and organizations — using Terraform.

## Authentication

All API calls use HTTP Basic Authentication. Provide credentials via provider arguments or environment variables:

| Environment variable       | Provider argument |
|----------------------------|-------------------|
| `OPENOBSERVE_ENDPOINT`     | `endpoint`        |
| `OPENOBSERVE_USERNAME`     | `username`        |
| `OPENOBSERVE_PASSWORD`     | `password`        |
| `OPENOBSERVE_ORG_ID`       | `org_id`          |

Environment variables are recommended to keep credentials out of Terraform state and source control.

## Example Usage

```hcl
provider "openobserve" {
  endpoint = "https://openobserve.example.com"
  username = "admin@example.com"
  password = var.oo_password
  org_id   = "default"
}
```
